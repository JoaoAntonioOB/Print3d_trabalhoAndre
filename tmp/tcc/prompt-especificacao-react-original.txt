NOME DO PROJETO

Print3D Manager ERP

Sistema ERP para gerenciamento completo de empresas de impressão 3D.

==================================================================

OBJETIVO

O sistema deverá controlar toda a operação de uma empresa de impressão 3D, desde o orçamento até a entrega do produto.

O projeto deverá ser suficientemente profissional para ser utilizado comercialmente após o TCC.
